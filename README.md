# 手游延迟测试 网页点击版

ReactionStable 点击响应版本的独立网页移植。无需 Mac、Xcode 或 iOS 签名即可部署，在现代 Safari 中访问。

## 保留的功能

- 暖白与深绿的设置、成绩、累计管理界面，仅支持横屏。竖屏显示旋转提示，转为横屏后继续使用。
- 自定义图片、本地保存、保持比例完整呈现，测试前解码、上传与离屏 GPU 预热。
- 200–60000 ms 随机等待、默认 10 轮、可设 1–100 轮；抢跑重测同一轮、反馈 2 秒自动继续。
- 首次新按下响应，允许一指持续按住、第二指点击；不等待抬起或 click，移动不计分。
- 平均、最小、最大、总体标准差、逐轮相对未舍入平均值的差、并列极值标记。
- 全部有效样本参与 ex-Gaussian 多起点最大似然拟合，8 条起显示峰值；MAD 只标记偏离，不剔除。保留偏离回合提醒、中位数差及百分比。
- 按图片、等待范围、实测页面帧率、视口尺寸和计时方案分别累计；查看、暂停、恢复、切换条件、删除回合、重置累计。
- IndexedDB 保存图片、设置与成绩；JSON 备份导出、校验及确认后导入。重置累计保留当前图片、设置和上次有效成绩。
- 切后台、失焦、取消触摸、改变窗口尺寸、持续帧率变化、长时间卡顿时中止，保留已完成样本。
- PWA 清单及离线资源缓存；Safari 可通过分享菜单添加到主屏幕。

## 计时差异

| 环节 | 安卓原生版 | 网页版 |
| --- | --- | --- |
| 等待文字移除 | 窗口帧提交回调 | 移除 DOM 后等待后续 rAF 渲染机会，无法确认系统帧已提交 |
| 刺激帧 | OpenGL ES，glFinish 后读取 uptime | WebGL，finish 后读取 performance.now |
| 停止点 | MotionEvent 原始时间 | pointerdown 的原始 event.timeStamp，旧 epoch 基准作 timeOrigin 换算 |
| 帧率 | 获取并请求实际显示模式 | 从 rAF 间隔估计页面 fps，不能读出或锁定物理面板 Hz |
| 原始保存 | 纳秒整数，旧系统精度另受限制 | 浏览器毫秒浮点值，不伪造纳秒精度 |

GPU 完成不代表浏览器合成、屏幕扫描或实际出光完成。浏览器还可能限制时间戳粒度；两位小数只表示显示格式。网页与安卓不能保证相同绝对误差，成绩分别保存，不导入安卓记录或混合拟合。

网页没有通用的强制高刷权限 API。高刷由设备、Safari 和系统策略决定。部分 Safari 版本可在高级功能标志中关闭 `Prefer Page Rendering Updates near 60Hz` 后重新测量；选项是否存在及效果取决于系统版本。页面显示的是回调估计 fps，不是触控采样率或面板物理刷新率。

依据：[WebKit 高帧率说明](https://webkit.github.io/explainers/animation-frame-rate/)、[WebGL finish](https://developer.mozilla.org/en-US/docs/Web/API/WebGLRenderingContext/finish)、[Event.timeStamp](https://developer.mozilla.org/en-US/docs/Web/API/Event/timeStamp)、[requestAnimationFrame](https://developer.mozilla.org/en-US/docs/Web/API/Window/requestAnimationFrame)。

## 本地运行与部署

无框架、无运行依赖、无需编译；静态文件全部位于 `dist/`，可部署到支持 HTTPS 的静态托管平台。现有 Sites 站点已设置为公开访问，访客无需 ChatGPT 账号登录。

```powershell
node tools/serve.mjs
# 本机访问 http://127.0.0.1:4173
node --test tests/core.test.mjs
```

图片与成绩只存在当前浏览器；更换设备、浏览器或网站域名不自动同步。换域名前从旧网址导出备份，在新网址导入。清除网站数据可能丢失记录，先导出备份。首次资源加载需要网络，离线使用需先完整加载并成功缓存。

帽子云提供面向大陆线路优化的静态网站托管；静态部署免费，每月共用 10 GiB 免费流量，超额 0.43 元/GiB。平台分配的二级域名形如 `应用名-xxxx.maozi.io`。具体名称须以创建成功后的返回地址为准。操作参数与数据迁移步骤见 [部署帽子云](部署帽子云.md)。

## 验证

2026-11-03 完成 8 组核心自动检查，以及与当前安卓 ReactionFit.java 的 6 组数值对照：常量、零值、偏离样本、20 条近高斯、50 / 100 条长尾样本，μ、σ、τ、峰值、KS 和负对数似然差均小于 0.001。

通过独立临时配置的无头 Edge / 软件 WebGL 执行十轮持触第二指点击、抢跑重测、移动忽略及原始事件时间计算；后续检查覆盖保存重启、手机横竖屏及平板尺寸、暂停恢复、空回合中断保留旧成绩、重置、图片上传及备份往返。检查脚本 `tests/browser.mjs` 可用 `--resume <先前报告>` 复用已通过的真实注入十轮证据。

本地证据位于忽略提交的 `validation/`。这些是软件行为检查；没有真实 iPhone / iPad 的 Safari、触控采样和实际出光校准结果，也不能据桌面模拟声称 iOS 高刷或绝对精度已通过。

## 横屏版本 1.0.2

设置、成绩和累计管理仅在横屏提供。竖屏显示“请横屏使用”，不会启动测试；测试中转为竖屏会中止当前轮并保留已完成的有效成绩。回到横屏可查看成绩或重新开始。主屏幕清单继续指定 landscape；iOS 浏览器内使用旋转提示作为方向限制。
